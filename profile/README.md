# Django and Python utils

Open-source Django and Python libraries.

## Django UI libraries

These work together: helpers → menus → modals → datatables, with 2FA, the toolbox view, cards and the
report builder on top. Helpers, menus, modals, datatables, 2FA and the toolbox view continue Ian Jones's [jonesim](https://github.com/jonesim) libraries,
with thanks to Ian. The pip names changed but the Python import names did not.
